Beyond TrueAncestor

what PkgLens adds

PkgLens is one library-first tool, not two console utilities — so it also carries capabilities TrueAncestor never had.

✓ Package inspector GUI

Folder tree, file list, search/filter, recent history, and a built-in image, text, or hex viewer.

✓ Integrity `verify`

Structural bounds, header SHA-1, header AES-CMAC, signatures, and post-operation verification.

✓ EDAT / SDAT decrypt

SDAT keyless and EDAT via RAP or free key, including compressed golden-vector and block-integrity coverage.

✓ SELF header inspect

Reads program type, key revision, ELF header, segment compression, and NPDRM identity without decrypting.

✓ Cross-platform

Avalonia GUI and .NET CLI on Windows, macOS, and Linux.

✓ Scriptable output

Structured `--json` output across CLI inspection and mutation commands.

✓ PlayStation exports

Guided PS1 and PS2 Classics workflows, PSP PBP/ISO/CSO export, and Vita app/update/DLC/theme export.

✓ Library automation

Resumable batch jobs, package classification, matching, duplicate detection, and organization.

✓ Safe conversion guidance

Operation preflight, automatic key/RAP discovery, firmware analysis, and target compatibility reports.

Compressed-data verification is covered. The EDAT LZ path is checked against a range-coded compressed golden vector and expected plaintext, while compressed fSELF segments are rebuilt only when beneficial and byte-exactly recoverable.

Former backlog items now ship. Firmware-target profiles, automatic fSELF compression, resumable batch/catalog workflows, and PS1, PS2, PSP, and Vita package workflows are available from the GUI, with relevant operations also exposed through the CLI.

Generated coverage stays synchronized. README tables, this HTML report, GUI feature descriptions, and the CLI tagline come from this manifest; CI rejects stale generated output.
