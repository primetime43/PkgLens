Beyond TrueAncestor

what PkgLens adds

PkgLens is one library-first tool, not two console utilities — so it also carries capabilities TrueAncestor never had.

✓ Package inspector GUI

Folder tree, file list, and a built-in viewer — image (ICON0/PIC1), text, or hex dump.

✓ Integrity verify

Structural bounds, header SHA-1, and header AES-CMAC — confirmed against real packages.

✓ EDAT / SDAT decrypt

SDAT keyless, EDAT via RAP or free key — including a range-coded compressed golden vector, integrity checks, and expected plaintext.

✓ SELF header inspect

pkglens self reads program type, key revision, ELF header & NPDRM id — no keys.

✓ Cross-platform

Avalonia GUI + .NET CLI on Windows/macOS/Linux — not a Windows-only console app.

✓ Scriptable output

--json on the inspection commands for tooling and pipelines.

✓ PlayStation exports

Guided PS1 and PS2 Classics workflows, PSP PBP/ISO/CSO export, and Vita app/update/DLC/theme directory export.

✓ Library automation

Resumable batch jobs, package classification, base/update/DLC matching, duplicate detection, and library organization.

✓ Safe conversion guidance

Operation preflight, automatic key/RAP discovery, firmware analysis, post-operation verification, and target compatibility reports.

Compressed-data verification is covered. The EDAT LZ path is checked against a range-coded compressed golden vector and expected plaintext, while compressed fSELF segments are rebuilt only when they are beneficial and can be decrypted back to the original ELF bytes.

Former backlog items now ship. Firmware-target profiles, automatic fSELF compression, resumable batch/catalog workflows, and PS1, PS2, PSP, and Vita package workflows are available from the GUI, with relevant operations also exposed through the CLI.

Core/CLI and Avalonia headless GUI suites run in CI with dependency auditing, separate line/branch coverage gates, and published TRX/Cobertura reports.
